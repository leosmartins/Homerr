# Homerr
IaC para um servidor caseiro, com diversar aplicações, variando de mídia até IoT

## Estrutura de pasta
Para que o projeto se mantenha organizado, é necessário manter uma ordem lógica, devido o número de containers existentes.

```text
Homerr/
├── 📄 README.md
├── 📄 docker-compose.yml
├── 📁 config/
└── 📁 media/
    ├── 📁 movies
    └── 📁 series
```
